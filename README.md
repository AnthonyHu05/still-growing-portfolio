# Still Growing

A tree-inspired personal portfolio with four chapters: Roots, Trunk, Branches, and Toward the Light.

Live website: https://anthonyhu05.github.io/still-growing-portfolio/

This is a first draft. The biography, experiences, achievements, personal photographs, and project links are awaiting real material. Story content is stored in app.js; the landing page is in index.html; styles are in style.css. The botanical illustration is generated artwork.

GitHub Pages publishes the main branch from the repository root. All assets use relative paths and there is no build step.
